# EPL model report

Generated by `python epl/train_report.py` (seed 42). Data: 27067 matches, top-5 leagues, seasons 2011-12..2025-26 (football-data.co.uk).

- Train: everything before 2024-07-01; DC half-life chosen on CV = 365d (CV RPS by candidate: 365d=0.2018, 730d=0.2021 — evaluated inside train only).
- Protocol v2 (walk-forward): goal model refit every 30 days; LGB retrained at each holdout season boundary. Applied identically to every model row; combiner fitting unchanged.
- Stack combiner fit on OOF predictions, seasons ['1819', '1920', '2021', '2122'].
- Blend weight fit on seasons ['2223', '2324'] (stack out-of-sample there).
- Holdout: seasons 2024-25 + 2025-26, 3504 matches with 1X2 closing odds ({'PSC': 2650, 'B365C': 854}).

## Locked rules for everything after this report

1. Every experiment passes a PRE-REGISTERED adoption gate: metric + threshold stated before running (CV RPS improvement >= 0.0005 unless stated otherwise), documented adopt-or-REJECT here with numbers. Rejected features stay computed in features.csv, unused.
2. Calibration layers and blend weights never see their own training data (OOF/holdout-clean first-stage predictions only).
3. Counts get rate-x-exposure treatment; check missingness-as-signal before imputing.
4. Draws are the calibration crux — per-class reliability, always.
5. Betting features only after this report proves calibration, with honest EV framing: edges must clear the vig, and most won't.
